GraphMock: Visual Mockup Tool

ノードベースのインターフェース設計のためのビジュアルモックアップ作成ツールです。ノーコード開発プラットフォームのUI検討や、複雑なノード構造の可視化を目的として制作しました。

Features

Key Features

  • 動的ノード生成: 任意のタイミングでカスタムノードを追加可能
  • ポート管理: インプット・アウトプットポートの動的な構成
  • プロパティ編集: ノードごとに設定可能なパラメータのモックアップ
  • ビジュアル接続: ノード間の論理的な繋がりを視覚化

Technical

Technologies

  • Godot Engine 4.6
  • GraphEdit / GraphNode
  • Visual Prototyping

Development Goal

複雑なロジックを非エンジニアでも直感的に構築できるノーコードツールの土台として、GodotのGraphEditシステムがどこまで柔軟にカスタマイズ可能かを検証するプロトタイプです。ノードの動的な初期化や、インデックス外アクセスの回避などの堅牢な実装に注力しました。
